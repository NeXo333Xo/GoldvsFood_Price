# Gold_vsFood_Price
## Description
Little Project that is used to analyze the gold price and food consumer price. Taking monthly data from 2008-2020.
Food Consumer Index for Germany is normalized for 2020. 

## Data
Gold price:
https://de.investing.com/etfs/xetra-gold-chart 
German consumer food price:
https://www-genesis.destatis.de/datenbank/online/statistic/61111/table/61111-0004

# Requirements
- Python
- Conda
- Juypter
